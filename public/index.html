Instalação

Canais de instalação

A Beta é o canal público disponível hoje. A Stable será aberta quando a release cumprir os gates de publicação.

Antes de começar

O básico para rodar em um servidor, VPS ou LXC.

  • Docker Engine e Compose v2 Para o caminho Docker.
  • Debian ou Ubuntu com systemd Para o binário da release.
  • Porta livre, com 8080 como padrão Você pode informar outra porta no instalador.
  • HTTPS e backup por sua conta Configure proxy, domínio e uma rotina de cópia.
Canal Beta consultando... última atualização: consultando data... Consultando o manifest do canal.
Instalação rápida 
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/beta/install.sh && bash /tmp/contabase-install.sh

O instalador pergunta porta, URL e proxy. O menu oferece Docker, binário da release ou código-fonte.

docker-compose.yml 
services:
  contabase:
    image: ghcr.io/contabase-app/contabase:v1.0.0-beta.6
    container_name: contabase
    restart: unless-stopped
    env_file:
      - .env.docker
    ports:
      - "127.0.0.1:${PORT:-8080}:8080"
    volumes:
      - ./data:/app/data
      - ./uploads:/app/uploads
      - ./backups:/app/backups

Copie o .env.docker e gere os secrets no guia Docker antes de subir a stack.

Terminal 
export CONTABASE_VERSION=v1.0.0-beta.6
git clone --branch "$CONTABASE_VERSION" https://github.com/contabase-app/contabase.git
cd contabase
./scripts/install.sh

No menu do instalador, escolha a opção de código-fonte/systemd. O guia completo fica em instalação.

Versão fixa 
A versão será exibida após consultar o canal.

O comando com versão fixa usa a tag exibida acima. Não use main, beta ou latest como versão.

Já instalado? Atualize com sudo contabase-update vX.Y.Z para uma tag fixa ou sudo contabase-update --channel beta para acompanhar o canal. Veja o guia de atualização.

Transparência

Saiba exatamente o que você está executando.

A instalação pública é uma cadeia de arquivos verificáveis. Cada etapa tem uma responsabilidade e pode ser lida antes da execução.

  1. 01

    Bootstrap do canal

    O arquivo /beta/install.sh consulta o manifest do canal e baixa o instalador da tag publicada. Ele não executa o conteúdo do manifest.

    Abrir o script bruto Ler como texto Código no GitHub
  2. 02

    Manifest da versão

    /channels/beta.json declara a tag Beta atual. A página usa esse manifest para exibir a versão, a data e montar o comando com versão fixa.

    Abrir o manifest Código no GitHub
  3. 03

    Instalador da tag

    O instalador oficial da tag baixa o helper e valida a versão e os artefatos da release antes de encaminhar a instalação.

    Script da tag Release da versão Checksums
  4. 04

    Método escolhido

    O instalador guiado encaminha para Docker, binário de release ou source. Cada método tem seu próprio guia e seus próprios requisitos.

    Docker LXC/VPS Source

Dúvidas frequentes

Perguntas rápidas

Respostas curtas para as decisões que aparecem antes e depois do primeiro deploy.

Meus dados ficam salvos onde?

No banco SQLite da sua instalação, dentro do volume ou diretório que você configurar. O ContaBase não envia dados financeiros para servidores de terceiros.

Preciso saber programar para usar?

Não no caminho guiado. O instalador pergunta porta, URL e proxy, e encaminha para Docker ou para o binário da release. A compilação por source exige Go e Node.

Serve para a família e para o negócio ao mesmo tempo?

Sim. O sistema é multiusuário e separa contextos em workspaces Pessoal e Business, com permissões por workspace.

Como faço backup?

O painel administrativo exporta o banco em .db. Para uma cópia completa, preserve também data/uploads e os segredos do ambiente. Agende uma rotina para um destino externo e teste o restore. Veja o guia de backup.

Posso contribuir com o projeto?

Sim. O projeto é aberto sob AGPL-3.0. Contribuições de código, tradução, documentação e relatos de bugs passam pelo repositório oficial.

Qual é a diferença entre o canal Beta e o comando com versão fixa?

O canal Beta consulta /channels/beta.json e instala a tag publicada no momento. O comando com versão fixa usa a tag exibida nesta página e não muda quando o canal avançar.
