Controle

O que fica sob seu controle

O ContaBase não é um SaaS. A instalação, o banco e as chaves ficam no ambiente que você administra.

Privacidade por arquitetura

Os dados financeiros ficam na sua instalação. Não há telemetria, analytics ou envio de dados para terceiros.

Self-hosted
Roda em Docker, VPS ou LXC. Você decide onde e como a aplicação é executada, sem depender de uma nuvem externa para operar.
Multiusuário
Pessoas da mesma casa ou equipe podem compartilhar a organização financeira com permissões por workspace.
Workspaces
Separe a vida pessoal e o negócio em ambientes Pessoal e Business, com dados e contexto próprios.
Organização
Contas, cartões, lançamentos, faturas, metas e relatórios no mesmo lugar, com histórico e fechamento mensal.
Investimentos Experimental
O cadastro e as novas aplicações estão em evolução. Adoção histórica e resgates financeiros das novas aplicações ainda não estão disponíveis.

Instalação

Comece pela Beta pública.

O canal Beta é o caminho disponível hoje. O instalador guiado escolhe entre Docker, binário de release ou source e pergunta os dados de acesso.

Canal Beta consultando... Consultando o manifest do canal.

Stable: não publicada. Consulte as Releases para ver as versões publicadas.

Instalação rápida 
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/beta/install.sh && bash /tmp/contabase-install.sh
Versão fixa 
A versão será exibida após consultar o canal.

O comando com versão fixa usa a tag exibida acima. Não use main, beta ou latest como versão.

Docker Compose

Instalação com Docker Compose a partir de um clone da tag publicada. O instalador guiado pergunta porta, URL e proxy.

Guia Docker

Linux, VPS ou LXC

Binários oficiais da GitHub Release com systemd. Indicado para VPS ou LXC sem Docker.

Guia LXC/VPS

Compilação por source

Compilação local com Go e Node para quem quer revisar ou adaptar o código.

Guia de instalação

Atualização

Use sudo contabase-update vX.Y.Z ou sudo contabase-update --channel beta em uma instalação existente.

Transparência

Saiba exatamente o que você está executando.

A instalação pública é uma cadeia de arquivos verificáveis. Cada etapa tem uma responsabilidade e pode ser lida antes da execução.

  1. 01

    Bootstrap do canal

    O arquivo /beta/install.sh consulta o manifest do canal e baixa o instalador da tag publicada. Ele não executa o conteúdo do manifest.

    Abrir o script bruto Ler como texto Código no GitHub
  2. 02

    Manifest da versão

    /channels/beta.json declara a tag Beta atual. A página usa esse manifest para exibir a versão e montar o comando com versão fixa.

    Abrir o manifest Código no GitHub
  3. 03

    Instalador da tag

    O instalador oficial da tag baixa o helper e valida a versão e os artefatos da release antes de encaminhar a instalação.

    Script da tag Release da versão
  4. 04

    Método escolhido

    O instalador guiado encaminha para Docker, binário de release ou source. Cada método tem seu próprio guia e seus próprios requisitos.

    Docker LXC/VPS Source
Baixar, inspecionar e executar 
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/beta/install.sh
less /tmp/contabase-install.sh
bash /tmp/contabase-install.sh

Ler apenas o bootstrap não audita a instalação inteira. Confira também o manifest, o instalador da tag e os checksums dos artefatos antes de executar.
